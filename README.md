# Marvido
A personalized booking website for our apartment, built as an alternative to Booking.com.
 
## Info
**Frontend:** HTML, CSS, JavaScript

**Backend:** Node.js, Express.js

**Database:** SQLite

**Deployment:** nginx

### Installation
-Node.js (v18+ recommended)
-npm

```bash
git clone https://github.com/<yourUsername>/Marvido.git
cd Marvido/server
npm install
```
### Running locally
```bash
npm run dev / node server.js
```
The site will be available at `http://localhost:3000` (or whatever port you set in `.env`).
